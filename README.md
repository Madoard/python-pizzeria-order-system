### ╰┈➤ ꒰ 🍽️ ꒱ Menu & Pricing Matrix

Customers can combine two pizza categories (**Savory** or **Sweet**) across three sizes (**Small**, **Medium**, or **Large**):

| 🍕 Size | 🧀 Savory Pizza (`SP`) | 🍫 Sweet Pizza (`SW`) |
| :---: | :---: | :---: |
| **S** *(Small)* | `$ 30.00` | `$ 34.00` |
| **M** *(Medium)* | `$ 45.00` | `$ 48.00` |
| **L** *(Large)* | `$ 60.00` | `$ 66.00` |

<p align="center">‧₊˚ ☁️⋅♡𓂃 ࣪ ִֶָ☾. ─────────────────────── ‧₊˚ ☁️⋅♡𓂃 ࣪ ִֶָ☾.</p>

### ╰┈➤ ꒰ 🧾 ꒱ How It Was Built

* **₊˚🌿 Continuous Order Loop (`while`):** Structured an interactive loop allowing multiple items to be added in a single session while validating flavor and size inputs.
* **₊˚🍅 Decision Matrix (`if / elif / else`):** Implemented nested conditional branches mapping each combination of flavor (`SP` / `SW`) and size (`S` / `M` / `L`) to its respective price.
* **₊˚🌿 State Accumulation & Sanitization:** Used a running `total` accumulator variable alongside `.strip().upper()` string normalization and formatted `f-strings` for the final receipt.
